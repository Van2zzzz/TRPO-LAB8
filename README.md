# 🍽️ Система "Ресторан"

## 📋 Назначение системы
Информационная система для автоматизации процессов работы ресторана, включая управление меню, обработку заказов, выставление счетов и прием платежей.

## 🎯 Основные функции системы

### 1. **Управление меню**
- Просмотр ассортимента блюд и напитков
- Добавление новых позиций в меню
- Редактирование существующих блюд (цена, описание, наличие)
- Удаление устаревших позиций

### 2. **Оформление заказов**
- Формирование заказа клиентом из меню
- Выбор столика и количества гостей
- Учет специальных пожеланий (аллергии, диетические ограничения)
- Возможность модификации заказа

### 3. **Работа кухни**
- Автоматическая передача заказа на кухню
- Отслеживание статуса приготовления (ожидание, готовится, готово)
- Уведомление официанта о готовности заказа

### 4. **Финансовые операции**
- Автоматическое формирование счета
- Поддержка различных способов оплаты (наличные, карта, онлайн)
- Печать фискального чека
- Ведение истории платежей

### 5. **Аналитика и отчетность**
- Отчеты по популярным блюдам
- Анализ выручки за период
- Учет рабочего времени персонала
- Контроль остатков продуктов

## 👥 Роли пользователей

### **Клиент**
- Просмотр меню
- Формирование заказа
- Оплата счета
- Просмотр истории заказов

### **Официант**
- Прием заказов от клиентов
- Передача заказов на кухню
- Отслеживание статуса заказов
- Выставление счетов

### **Администратор**
- Управление меню (добавление/редактирование позиций)
- Подтверждение заказов
- Формирование отчетов
- Управление учетными записями персонала

### **Повар**
- Просмотр поступивших заказов
- Изменение статуса приготовления блюд
- Контроль наличия ингредиентов

## 🗂️ Модель данных

### Основные сущности:
- **Блюдо** (название, описание, цена, категория, время приготовления)
- **Заказ** (номер, дата, столик, статус, сумма)
- **Позиция заказа** (блюдо, количество, комментарий)
- **Счет** (номер, дата, сумма, способ оплаты, статус)
- **Клиент** (идентификатор, история заказов)
